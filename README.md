# やさしいナンプレ

広告なし・登録なし・ずっと無料。ねこと いっしょに、1面ずつ たのしく とける ナンプレ(数独)です。
とくに、スマホに なれていない 高齢の方でも、説明なしで すぐ遊べることを いちばん大事にしています。

**遊ぶ: https://roguepink.github.io/nanpure/**

## どんなアプリ

- いちばん定番の 9×9 マス。ステージ 1 は とても やさしく、少しずつ むずかしくなる(終わりなし)
- 数字の並びは、点対称・左右対称などの「きれいな形」。人が 理づめで とける問題だけ(答えは 1つ)
- **同じ面は 二度と出ない。**ステージ番号ごとに ちがう問題を その場で作る。念のため、出た面の印を 端末に覚えて、ぶつかったら 作りなおす
- まちがえた数字は 赤く出て、すぐ消える(ゲームオーバーなし)。こまったら 💡ヒント(理由つきで 1マス 教えてくれる)
- ✏️メモ(小さい下書き)、★3つの評価、3面ごとに「なかま」の動物が ふえる
- 進みぐあいは その端末の中だけに保存(送信なし)。途中で閉じても つづきから

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても遊べる

## ファイル

- `index.html` 画面と操作 / `engine.js` 問題を作る・とく・ヒント
- `tools/make_art.py` アイコンと紹介画像(ogp.jpg)を作る
- `tests/engine_test.js` 問題づくりの確認(Mac の jsc で動く):
  `/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc engine.js tests/engine_test.js -- 300`
- `tests/flow.py` 本当のタップで 2面クリアまで通す確認 / `tests/check.py` いろいろな画面の大きさで写真を撮る

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ
- 問題の作り方(`engine.js` の `plan` や `SYMS`)を変えると、まだ遊んでいない ステージの問題が かわる(遊び途中の面は 保存ずみなので そのまま)
